# 🚀 Portfolio Project

Welcome to the **Portfolio Project** repository! This is a modern, full-stack monorepo containing both the frontend and backend applications for my personal portfolio. 

## 📁 Repository Structure

This repository is divided into two main parts:

- [**`front_`**](./front_/) - The User Interface, built with Next.js, React 19, and Tailwind CSS.
- [**`back_`**](./back_/) - The API and Admin Panel, built with Laravel 12 and Filament PHP.

## 🛠️ Tech Stack Overview

### Frontend
- **Framework:** Next.js 16 (App Router)
- **UI Library:** React 19
- **Styling:** Tailwind CSS v4
- **Components:** Radix UI / shadcn/ui
- **State/Data Fetching:** SWR, Axios

### Backend
- **Framework:** Laravel 12
- **Admin Panel:** Filament PHP v4
- **Authentication:** Laravel Sanctum
- **Database:** SQLite / MySQL / PostgreSQL
- **Testing:** Pest PHP

## 🚀 Getting Started

To get the project running locally, you will need to set up both environments. Please refer to the specific README files in each folder for detailed instructions:

1. **Backend Setup:** See the [Backend README](./back_/README.md) for database, environment, and API setup.
2. **Frontend Setup:** See the [Frontend README](./front_/README.md) for dependency installation and dev server instructions.
